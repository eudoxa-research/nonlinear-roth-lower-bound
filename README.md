# An improved lower bound in the nonlinear Roth theorem

**Bryan Zachary Bu, Karam Gill, Hyunjun Yi**

September 2026.

DOI: [10.5281/zenodo.23343401](https://doi.org/10.5281/zenodo.23343401)

## Abstract

We build subsets of {1, …, N} of size N^0.77509… with no configuration {x, x+y, x+y²}, improving Younis’s exponent 0.76850, by running his iterated-difference framework at modulus 145. We also solve the optimisation exactly, with big-integer certificates, at moduli 65 and 85.
